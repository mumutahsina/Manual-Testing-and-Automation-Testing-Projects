# Manual-Testing-and-Automation-Testing-Projects

Welcome to our repository!  
This repository showcases two projects — Manual Testing and Automation Testing.

 Project Contents

Manual Testing Project
A collection of documents related to manual software testing, including:
- Test Plan
- Test Cases
- Test Report
- Bug reports

Automation Testing Project
A set of Python automation scripts developed and executed using PyCharm, including:
- Automated test scripts
- Supporting functions and modules
- Sample test execution results

 Tools & Technologies
- Manual Testing: Microsoft Word, Microsoft Excel  
- Automation Testing: Python, PyCharm (Selenium, pytest, pytest-html)
